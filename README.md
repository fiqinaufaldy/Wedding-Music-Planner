# FNVerse Wedding Song Planner

Static HTML/CSS/JS wedding music planner.

## Structure
- `index.html` — app shell and modals
- `css/style.css` — layout and styling
- `js/app.js` — application logic, filters, CRUD, popup and YouTube parser
- `js/songs.js` — Wedding Song data

Run with VS Code Live Server for YouTube embeds to have a normal HTTP origin.
